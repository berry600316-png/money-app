開發與驗收都以本檔為準；要改任何一條，先與 User 確認後再改本檔。

## 分類與付款方式

| D-15 | 每種類型（支出、收入）至少保留一個啟用中的分類；付款方式至少保留一個啟用中的。 |

## 統計

| # | 決策 |
|---|---|
| D-30 | 一律以自然月（1 日到月底，iPhone 本地時區）統計。 |
| D-31 | 統計頁內容：本月支出／收入／結餘、與上月同期比較、支出分類比例（可點進明細）、收入來源、近六個月支出趨勢。不做年度總覽。 |

## 資料安全

| # | 決策 |
|---|---|
| D-40 | 選好備份檔後有兩種還原：「全部取代」（用備份檔完全取代目前資料）或「只還原某段期間」（D-44）。兩種都會在還原前自動保留 1 份「還原前資料」，設定頁可退回（退回前也要確認）。 |
| D-44 | 指定期間還原 = 取代該期間：目前資料中起迄日期（含，本地時間）內的交易移除，換成備份中同期間的交易；期間外的交易、所有設定都不動（2026-10-10 User 確認 Q27–Q31）。 |
| D-45 | 期間用起、迄兩個日期選，預設為備份檔中最早與最晚的交易日期；確認畫面寫出「備份這段期間 N 筆，會取代目前同期間 M 筆」。 |
| D-46 | 備份期間內的交易用到、但目前沒有的分類或付款方式，會自動加回來（排在最後）；已存在的分類與付款方式維持現狀。同一個分類在備份與目前的收支類型不同時，不還原並提示。 |
| D-47 | 同一筆交易（同 id）在目前資料中被改到期間外的日期時，以備份版本為準，移回期間內；確認畫面會另外註明筆數。 |
| D-41 | 備份提醒：距上次備份 >30 天且期間新增 ≥20 筆 → 首頁頂端顯示可關閉的一行提示；關閉後 7 天仍未備份再出現。設定頁持續顯示「上次備份：X 天前」。 |
| D-42 | CSV 欄位：日期、時間、類型、金額（一律正數）、分類、付款方式、商家、備註。UTF-8 加 BOM。 |
| D-43 | 新版本在下次開啟 App 時生效；新增面板開著時不重新載入，不會遺失輸入中的資料。 |

## 資料模型補充

- 交易欄位完全照第 0 章 0.8。`occurredAt`、`createdAt`、`updatedAt` 存 ISO 8601（UTC），顯示與月份計算一律換算成 iPhone 本地時間。
- Category 在第 0 章欄位之外多一個 `sortOrder`（整數），用來固定顯示順序；新增的分類排在同類型最後。
- PaymentMethod 同樣多一個 `sortOrder`。

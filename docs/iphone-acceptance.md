# iPhone 實機驗收清單（第 6 階段）

規格 0.17 要求「未經實機驗證的 iOS 功能不得宣稱完成」。下列項目只能在實體 iPhone（iOS 26）上驗證，
請在部署到 GitHub Pages 後逐項操作，打勾或記下狀況回報。電腦上已驗證過的項目列在最後供參考。

## A. 安裝

- [ ] A1 Safari 開啟 `https://berry600316-png.github.io/money-app/`，畫面正常（不是空白）。
- [ ] A2 分享 → 加入主畫面：名稱顯示「Money」，圖示是深綠底三條線（方案 A），沒有白邊。
- [ ] A3 從主畫面開啟：沒有 Safari 網址列，是獨立畫面。
- [ ] A4 頂端狀態列（時間、電池）清楚可讀，背景與 App 的暖白色一致，沒有一條白色或黑色色塊。
- [ ] A5 動態島周圍沒有內容被遮住；底部導覽列沒有壓到 Home 橫條。
- [ ] A6 設定頁「離線使用」顯示「已就緒」（第一次開啟可能要等幾秒，必要時關掉再開一次）。

## B. 記帳操作

- [ ] B1 點「＋」→ 輸入金額 → 儲存，整個流程 10 秒內完成，不用看說明。
- [ ] B2 快速連按數字鍵（例如 1、2、8 很快按完），金額完整顯示 128，沒有漏字。
- [ ] B3 點商家欄位叫出鍵盤：面板會往上移，「儲存」按鈕在鍵盤上方看得到也按得到。
- [ ] B4 收起鍵盤後，數字鍵盤回來，畫面沒有卡在錯誤位置、沒有留白。
- [ ] B5 日期：點「今天」跳出 iOS 日期選擇器，不能選未來日期。
- [ ] B6 付款方式：點「信用卡」跳出 iOS 選單。
- [ ] B7 面板往下拉可以關閉；點灰色背景也可以關閉。
- [ ] B8 點一筆紀錄 → 修改金額 → 更新；再點一筆 → 刪除 → 提示列點「復原」，紀錄回來。
- [ ] B9 明細頁搜尋：鍵盤的「搜尋」鍵可以收起鍵盤；搜尋結果正確。
- [ ] B10 列表捲動順暢；切到統計再切回明細，捲動位置保留。
- [ ] B11 統計頁點分類會跳到該分類的明細；點近六個月的長條可以切換月份。

- [ ] C3 新增一筆、修改一筆、查詢明細、查看統計，全部正常。
- [ ] C4 再次滑掉 App 重開，剛才的資料都還在。
- [ ] C5 關閉飛航模式。

## D. 資料保存與備份

- [ ] D1 記幾筆之後，設定頁「持久保存」顯示的狀態（記下是「已啟用」或「未啟用」，兩者都可能，App 只是如實顯示）。
- [ ] D2 設定 → 匯出完整備份 → 儲存備份… → 跳出 iOS 分享選單 → 儲存到檔案 → 我的 iPhone。在「檔案」App 看得到 `caijie-backup-日期.json`。
- [ ] D3 設定頁顯示「上次備份：今天」。
- [ ] D4 匯出交易 CSV → 存到檔案 → 用 Numbers 開啟，中文正常、欄位是 日期／時間／類型／金額／分類／付款方式／商家／備註。
- [ ] D5 從備份還原 → 從「檔案」選剛才的 JSON → 選「全部取代」→ 確認畫面顯示正確的筆數 → 取代並還原 → 資料正確。
- [ ] D5b 先修改、刪除某個月的幾筆紀錄 → 從備份還原 → 選「只還原某段期間」→ 用 iOS 日期選擇器選那個月的起迄日 → 下一步 → 確認筆數 → 取代這段期間。那個月回到備份時的樣子，其他月份（包括備份之後才新增的紀錄）完全不變。
- [ ] D6 設定頁出現「退回到還原之前」，點它可以退回。
- [ ] D7 選一個不是備份的檔案（例如 CSV），App 顯示錯誤訊息，資料沒有變動。

## D2. 薪資單與項目歷史

- [ ] S1 記一筆 → 切到「收入」→ 選「薪資」分類 → 出現「用薪資單記錄明細 ›」→ 點它打開新增薪資單。
- [ ] S2 新增薪資單：所屬月份與發薪日用 iOS 選擇器挑；金額欄位跳出數字鍵盤；鍵盤出現時「儲存」按鈕仍看得到。
- [ ] S3 儲存後首頁出現一筆標「薪資單」的收入，金額 = 實領；點它會打開那張薪資單，不是一般的編輯面板。
- [ ] S4 第二個月新增：固定項目（本薪、勞健保）自動帶上個月金額，變動項目（獎金、加班費）是空的。
- [ ] S5 薪資單點任一項目 → 項目歷史：最新金額、較上次差異、直條圖、累計／平均、逐月紀錄都正確；切換 3／6／12 個月與自訂月份正常；點直條顯示該月金額。
- [ ] S6 統計 → 收入來源「薪資」→ 薪資單列表；沒有建立的月份顯示「尚無薪資單・補建」。
- [ ] S7 設定 → 薪資項目：新增、改名、停用、切換固定／變動；改名後舊月份在項目歷史顯示「當時：…」。
- [ ] S8 刪除一張薪資單 → 提示列點「復原」，薪資單和那筆收入都回來。

## D3. 信用卡模組

先依 `docs/shortcut-setup.md` 建好捷徑，並在「設定 › 付款方式」把信用卡的類型設為「信用卡」、填末四碼。

- [ ] K1 捷徑設定說明第四節 V1–V7 逐項實測並回報（特別是 **V3：Richart Life 通知原文**）。
- [ ] K2 明細頁頂端看得到「匯入刷卡紀錄」「信用卡核對」兩個按鈕。
- [ ] K3 匯入刷卡紀錄：檔案選擇器能進到「我的 iPhone › MoneyApp › Inbox」、能一次選多個 JSON。
- [ ] K4 預覽的商店、金額、時間、卡片正確；按「匯入 N 筆」後首頁與統計立即更新。
- [ ] K5 同一批檔案再匯入一次：全部顯示「已匯入過」，沒有重複記帳。
- [ ] K6 信用卡核對 → 匯入帳單 → 選台新 PDF 電子帳單；有密碼的會要求輸入，輸入錯誤有提示。
- [ ] K7 **請提供一份遮蔽個資的台新 PDF 帳單**：比對解析出的明細筆數、日期、金額是否和 PDF 完全相同（目前只用模擬帳單測過）。
- [ ] K8 核對頁：上方的「X / Y 筆已核對」與三種問題的筆數合理；點任一筆問題可在面板內直接處理（補記、配對、等待下期）。
- [ ] K9 補記一筆「帳單有、記帳沒有」：明細出現新的支出，日期是消費日，核對頁該筆變成已核對。
- [ ] K10 修改一筆已核對的記帳金額：核對頁顯示「記帳已變更」，明細上的勾勾消失。
- [ ] K11 飛航模式下開啟 App，匯入帳單 PDF 仍可解析（PDF 元件已離線快取）。
- [ ] K12 匯入一週真實刷卡通知：記下「新的刷卡紀錄」「需要你確認」「不會匯入」各幾筆。若真消費大多落在「需要你確認」，把其中 2–3 則通知原文（遮蔽卡號）提供給開發，用來放寬規則（D-96）。
- [ ] K13 匯入真實台新帳單：記下「無法辨識」幾行；把遮蔽個資後的那幾行文字提供給開發，用來寫台新專用格式。
- [ ] K14 若有第二家銀行的 App：照 `docs/shortcut-setup.md`「二之一」再建一個自動化。兩家的通知一起匯入時，沒有卡號的通知會分別問「「某 App」的刷卡是哪張卡？」；選過一次後，下次各自記得。

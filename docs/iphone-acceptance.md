# iPhone 實機驗收清單（第 6 階段）

規格 0.17 要求「未經實機驗證的 iOS 功能不得宣稱完成」。下列項目只能在實體 iPhone（iOS 26）上驗證，
請在部署到 GitHub Pages 後逐項操作，打勾或記下狀況回報。電腦上已驗證過的項目列在最後供參考。

## A. 安裝

- [ ] A1 Safari 開啟 `https://basd0123.github.io/money-app/`，畫面正常（不是空白）。
- [ ] A2 分享 → 加入主畫面：名稱顯示「Money」，圖示是深綠底三條線（方案 A），沒有白邊。
- [ ] A3 從主畫面開啟：沒有 Safari 網址列，是獨立畫面。
- [ ] A4 頂端狀態列（時間、電池）清楚可讀，背景與 App 的暖白色一致，沒有一條白色或黑色色塊。
- [ ] A5 動態島周圍沒有內容被遮住；底部導覽列沒有壓到 Home 橫條。
- [ ] A6 設定頁「離線使用」顯示「已就緒」（第一次開啟可能要等幾秒，必要時關掉再開一次）。

## B. 記帳操作

- [ ] B1 點「＋」→ 輸入金額 → 儲存，整個流程 10 秒內完成，不用看說明。
- [ ] B2 快速連按數字鍵（例如 1、2、8 很快按完），金額完整顯示 128，沒有漏字。
- [ ] B3 點商家欄位叫出鍵盤：面板會往上移，「儲存」按鈕在鍵盤上方看得到也按得到。
- [ ] B4 收起鍵盤後，數字鍵盤回來，畫面沒有卡在錯誤位置、沒有留白。
- [ ] B5 日期：點「今天」跳出 iOS 日期選擇器，不能選未來日期。
- [ ] B6 付款方式：點「信用卡」跳出 iOS 選單。
- [ ] B7 面板往下拉可以關閉；點灰色背景也可以關閉。
- [ ] B8 點一筆紀錄 → 修改金額 → 更新；再點一筆 → 刪除 → 提示列點「復原」，紀錄回來。
- [ ] B9 明細頁搜尋：鍵盤的「搜尋」鍵可以收起鍵盤；搜尋結果正確。
- [ ] B10 列表捲動順暢；切到統計再切回明細，捲動位置保留。
- [ ] B11 統計頁點分類會跳到該分類的明細；點近六個月的長條可以切換月份。

## C. 離線（規格 0.17 離線驗收）

完成 A6 後：

- [ ] C1 開啟飛航模式。
- [ ] C2 從主畫面重新啟動 App（先在多工畫面把它滑掉）。畫面正常、字體正常（金額是襯線字）。
- [ ] C3 新增一筆、修改一筆、查詢明細、查看統計，全部正常。
- [ ] C4 再次滑掉 App 重開，剛才的資料都還在。
- [ ] C5 關閉飛航模式。

## D. 資料保存與備份

- [ ] D1 記幾筆之後，設定頁「持久保存」顯示的狀態（記下是「已啟用」或「未啟用」，兩者都可能，App 只是如實顯示）。
- [ ] D2 設定 → 匯出完整備份 → 儲存備份… → 跳出 iOS 分享選單 → 儲存到檔案 → 我的 iPhone。在「檔案」App 看得到 `money-backup-日期.json`。
- [ ] D3 設定頁顯示「上次備份：今天」。
- [ ] D4 匯出交易 CSV → 存到檔案 → 用 Numbers 開啟，中文正常、欄位是 日期／時間／類型／金額／分類／付款方式／商家／備註。
- [ ] D5 從備份還原 → 從「檔案」選剛才的 JSON → 確認畫面顯示正確的筆數 → 取代並還原 → 資料正確。
- [ ] D6 設定頁出現「退回到還原之前」，點它可以退回。
- [ ] D7 選一個不是備份的檔案（例如 CSV），App 顯示錯誤訊息，資料沒有變動。

## E. 更新

- [ ] E1 之後發布新版本時，下次從主畫面開啟（或切到背景再回來）就換成新版，資料都還在。
- [ ] E2 正在新增時切到別的 App 再切回來，輸入到一半的內容還在，沒有被重新載入洗掉。

## F. 系統設定

- [ ] F1 設定 → 輔助使用 → 顯示與文字大小 → 更大的文字，調大一兩級後開啟 App：文字變大、版面沒有破掉。
- [ ] F2 iPhone 設成深色模式時，App 維持暖白（D-04）。
